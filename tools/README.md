# Tools

## `gen_wards.py`

Generates the schematic ward lattice used by `src/data/wards.ts`.

A Lloyd-relaxed Voronoi partition of a star-shaped city boundary, in real WGS84
coordinates around Bengaluru, plus a seeded set of indicator values. Requires
`numpy` and `scipy`.

```bash
pip install numpy scipy
python3 tools/gen_wards.py > wards.json
```

To rebuild `src/data/wards.ts` from that output:

```bash
python3 - <<'PY'
import json
d = json.load(open('wards.json'))
open('src/data/wards.ts','w').write(f'''// AUTO-GENERATED by tools/gen_wards.py — do not edit by hand.
//
// SCHEMATIC ward geometry. Not official ward boundary data.
// Seed: {d["seed"]}

import type {{ Ward }} from "@/types";

export const WARD_LATTICE_SEED = {d["seed"]};
export const WARD_GENERATOR = "{d["generator"]}@{d["generatorVersion"]}";

const RAW_BOUNDARY = {json.dumps(d["boundary"])};
const RAW_WARDS = {json.dumps(d["wards"], indent=2)};

export const CITY_BOUNDARY = RAW_BOUNDARY as [number, number][];
export const WARDS = RAW_WARDS as unknown as Ward[];
''')
PY
```

### Swapping in real geometry

Replace `RAW_BOUNDARY` and `RAW_WARDS` with real ward polygons in the same
shape. Nothing in `src/components` or `src/lib` needs to change — the
projection in `src/lib/geo.ts` fits whatever bounds it is given.

When you do, remove the "Schematic geometry" note in `src/app/page.tsx` and set
the geometry row on `/data` to its real grade. Do not remove the synthetic
markers on indicators that are still generated.
